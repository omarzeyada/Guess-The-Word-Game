# 🎮 Guess the Word Game

A simple and fun word guessing game built with HTML, CSS, and JavaScript.

## 🧠 Game Idea

The game randomly picks a word, and the player has to guess it by entering different attempts. After each try, the player receives feedback whether the word is correct or not. The game can be restarted any time for a new challenge.

## 🔧 Technologies Used

- HTML  
- CSS  
- JavaScript
